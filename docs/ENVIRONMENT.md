# Environment Variables

All configuration comes from environment variables. Locally they live in a single root `.env`
(`pnpm setup:env` creates it from `.env.example` with generated secrets). Package scripts load it with
`dotenv -e ../../.env`. In production set them in the platform's secret store — never commit a real `.env`.

`apps/web/src/lib/env.ts` validates everything at first use with Zod and fails fast with a clear message.

| Variable                                                                              | Required        | Default                                 | Description                                                                                                                                                                                                                                                                                                                                                                                                                               |
| ------------------------------------------------------------------------------------- | --------------- | --------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `DATABASE_URL`                                                                        | yes             | —                                       | Postgres connection for Prisma (web, jobs, seed).                                                                                                                                                                                                                                                                                                                                                                                         |
| `DIRECT_URL`                                                                          | prod migrations | —                                       | Direct (unpooled) Postgres connection used only to run `prisma migrate deploy` in production (`DATABASE_URL` is the pooled one). Not read by the app.                                                                                                                                                                                                                                                                                     |
| `TEST_DATABASE_URL`                                                                   | tests           | —                                       | Separate database for integration tests; must contain `_test`. Reset on every run.                                                                                                                                                                                                                                                                                                                                                        |
| `APP_URL`                                                                             | yes             | `http://localhost:3000`                 | Public origin. Used for links in emails/invites and the CSRF origin check.                                                                                                                                                                                                                                                                                                                                                                |
| `NEXT_PUBLIC_APP_URL`                                                                 | yes             | same                                    | Same value, exposed to the browser.                                                                                                                                                                                                                                                                                                                                                                                                       |
| `MARKETING_URL`                                                                       | prod            | —                                       | Marketing site origin (apex), e.g. `https://example.com`.                                                                                                                                                                                                                                                                                                                                                                                 |
| `HOST_ROUTING`                                                                        | no              | `off`                                   | `on` = one deployment serves the marketing site on `MARKETING_URL` (+ `www.`) and the dashboard + APIs on `APP_URL`; cross-site paths redirect. Other hosts (localhost, `*.netlify.app` and deploy previews) are never rerouted.                                                                                                                                                                                                          |
| `MARKETING_ALIAS_HOSTS`                                                               | no              | —                                       | Extra comma-separated hostnames that redirect to `MARKETING_URL`.                                                                                                                                                                                                                                                                                                                                                                         |
| `NEXT_PUBLIC_APP_STORE_URL`                                                           | no              | placeholder                             | App Store link shown in employee invite instructions.                                                                                                                                                                                                                                                                                                                                                                                     |
| `SESSION_SECRET`                                                                      | yes             | —                                       | ≥32 random bytes (hex). HMAC key for CSRF tokens and cookie integrity.                                                                                                                                                                                                                                                                                                                                                                    |
| `SESSION_TTL_DAYS`                                                                    | no              | `14`                                    | Manager session lifetime (sliding).                                                                                                                                                                                                                                                                                                                                                                                                       |
| `REQUIRE_EMAIL_VERIFICATION`                                                          | no              | `true` in production, `false` otherwise | When `true`, creating an organisation and org-scoped manager routes return `EMAIL_NOT_VERIFIED` until the address is verified. Set explicitly to override the default.                                                                                                                                                                                                                                                                    |
| `MOBILE_JWT_SECRET`                                                                   | yes             | —                                       | HS256 secret for device access tokens.                                                                                                                                                                                                                                                                                                                                                                                                    |
| `MOBILE_JWT_KEY_ID`                                                                   | no              | `v1`                                    | `kid` header; bump when rotating `MOBILE_JWT_SECRET` (old tokens expire within 15 min).                                                                                                                                                                                                                                                                                                                                                   |
| `MOBILE_ACCESS_TOKEN_TTL_SECONDS`                                                     | no              | `900`                                   | Access token lifetime.                                                                                                                                                                                                                                                                                                                                                                                                                    |
| `MOBILE_REFRESH_TOKEN_TTL_DAYS`                                                       | no              | `60`                                    | Refresh token lifetime (rotated on every use).                                                                                                                                                                                                                                                                                                                                                                                            |
| `INTEGRATION_ENCRYPTION_KEY`                                                          | yes             | —                                       | 32 bytes base64. AES-256-GCM key for integration credentials and push tokens at rest.                                                                                                                                                                                                                                                                                                                                                     |
| `EMAIL_PROVIDER`                                                                      | no              | `console`                               | `console` (local default) logs emails, links included, to stdout; in production it logs only the subject and nothing is delivered. `resend` sends through the Resend HTTP API (`POST https://api.resend.com/emails`, 10 s timeout, redirects refused, no retries) and is the production setting; it needs `RESEND_API_KEY` and an `EMAIL_FROM` on a domain verified in Resend. `smtp` is reserved (no SMTP client installed; sends fail). |
| `EMAIL_FROM`                                                                          | no              | `Work Mode <no-reply@workmode.local>`   | From header (`address@domain` or `Name <address@domain>`). With `resend` its domain must be verified in Resend (production: `Work Mode <noreply@clockoff.online>`). With `resend`, a sender without a usable address or on a `.local` / `.localhost` / `.test` / `.example` / `.invalid` domain (the default included) makes `env()` throw in production and warn elsewhere, since Resend would reject every send.                        |
| `RESEND_API_KEY`                                                                      | if resend       | —                                       | Resend API key (`re_…`; "sending access" is enough). Only read when `EMAIL_PROVIDER=resend`. Missing (or containing inner whitespace) in production → `env()` throws at first use (the deploy fails loudly); elsewhere → a warning and every send fails (logged by `sendEmailSafely`). Never logged; Resend errors are logged as HTTP status + Resend error name/message with addresses and the key stripped.                             |
| `SMTP_HOST`, `SMTP_PORT`, `SMTP_USER`, `SMTP_PASSWORD`                                | if smtp         | —                                       | SMTP transport settings (reserved: `SmtpEmailProvider` cannot send yet).                                                                                                                                                                                                                                                                                                                                                                  |
| `APNS_KEY_ID`, `APNS_TEAM_ID`, `APNS_P8_BASE64`, `APNS_BUNDLE_ID`, `APNS_ENVIRONMENT` | no              | —                                       | When all set, `ApnsPushProvider` sends silent pushes (token-based auth, `.p8` key base64-encoded). Otherwise `NoopPushProvider` logs and devices rely on background refresh. `APNS_ENVIRONMENT` is `sandbox` or `production`.                                                                                                                                                                                                             |
| `TRUSTED_PROXY_HOPS`                                                                  | no              | `1`                                     | Number of reverse proxies that append to `X-Forwarded-For`; the client IP for rate limiting is read that many hops from the right. Production must sit behind a proxy that overwrites the header.                                                                                                                                                                                                                                         |
| `CLIENT_IP_HEADER`                                                                    | no              | —                                       | Header set by the hosting edge with the real client IP, used for rate limiting in preference to `X-Forwarded-For` (Netlify: `x-nf-client-connection-ip`). Only set it when the platform guarantees the header.                                                                                                                                                                                                                            |
| `RATE_LIMIT_BACKEND`                                                                  | no              | `memory`                                | `memory` (single process) or `redis`.                                                                                                                                                                                                                                                                                                                                                                                                     |
| `REDIS_URL`                                                                           | if redis        | —                                       | Redis for rate limiting / event bus adapter (future).                                                                                                                                                                                                                                                                                                                                                                                     |
| `JOBS_ENABLED`                                                                        | no              | `true`                                  | Set `false` to run the web app without the in-process scheduler (use `/api/jobs/tick`).                                                                                                                                                                                                                                                                                                                                                   |
| `CRON_SECRET`                                                                         | yes             | —                                       | Bearer secret for `POST /api/jobs/tick` (external cron). Must be 32+ characters in production.                                                                                                                                                                                                                                                                                                                                            |
| `LOG_LEVEL`                                                                           | no              | `info`                                  | pino level.                                                                                                                                                                                                                                                                                                                                                                                                                               |
| `DEV_TOOLS_ENABLED`                                                                   | no              | `true` locally                          | Enables `/api/dev/*` helpers (e.g. reading the last console email in Playwright). Must be unset/`false` in production.                                                                                                                                                                                                                                                                                                                    |
| `ALLOW_SEED`                                                                          | no              | —                                       | The demo seed refuses `NODE_ENV=production` and any non-local database unless this is exactly `true`. Never set it for production.                                                                                                                                                                                                                                                                                                        |
| `NODE_ENV`                                                                            | set by tooling  | —                                       | `production` enables `Secure` cookies and HSTS.                                                                                                                                                                                                                                                                                                                                                                                           |
| `PRISMA_LOG`                                                                          | no              | —                                       | `query` to log SQL in development.                                                                                                                                                                                                                                                                                                                                                                                                        |

## Generating secrets

```bash
node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"     # SESSION_SECRET / MOBILE_JWT_SECRET / CRON_SECRET
node -e "console.log(require('crypto').randomBytes(32).toString('base64'))"  # INTEGRATION_ENCRYPTION_KEY
```
